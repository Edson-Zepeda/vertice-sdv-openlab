GUÍA RÁPIDA

Dale forma a una ruta.

  1. Edita. Selecciona un nodo o conexión. También puedes usar los formularios.
  2. Calcula. Elige inicio y destino. El costo es la suma de las conexiones.
  3. Explora. Reproduce las decisiones reales del algoritmo.

Tab recorre controles. Enter selecciona. Las flechas mueven el nodo seleccionado; Mayús + flecha mueve más. Escape cancela la conexión.

Amplía con +, aleja con −. Arrastra el fondo para recorrer el grafo. Con el lienzo enfocado, las flechas desplazan la vista.

Ctrl + Z deshace. Ctrl + Mayús + Z rehace. Exporta JSON para conservar una copia.

Qué significa cada estado

Asentado: costo mínimo definitivo. Frontera: costo tentativo. Sin ruta: no existe un recorrido al destino. El algoritmo se detiene al asentar el destino.

Los ejemplos son grafos didácticos. Un empate admite varias rutas óptimas; se muestra una de forma reproducible.

Hasta 500 nodos y 4 000 conexiones. En grafos densos, amplía la vista o usa la lista de nodos y conexiones para editar.
